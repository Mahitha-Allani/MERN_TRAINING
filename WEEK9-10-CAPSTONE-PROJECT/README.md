WEEK9-10 CAPSTONE PROJECT – MERN STACK BLOG APPLICATION


📌 Project Overview

This repository contains the complete MERN Stack Capstone Project developed during Weeks 9–10 of MERN Stack training. The project demonstrates full-stack web application development using MongoDB, Express.js, React.js, and Node.js.

The application includes frontend and backend integration, REST APIs, authentication, database operations, deployment, and responsive UI implementation.

Backend Setup

Navigate to Backend Folder: 
cd WEEK9-10-CAPSTONE-PROJECT/BLOG-APP-BACKEND

Install Dependencies:
npm install

Start Backend Server
npm run dev


Frontend Setup

Navigate to Frontend Folder
cd WEEK9-10-CAPSTONE-PROJECT/BLOG-APP-FRONTEND

Install Dependencies
npm install

Run Frontend
npm run dev


Deployment
Frontend Deployment – Vercel

Deploy the frontend using:

Build Command
npm run build

Output Directory
dist

Backend Deployment – Render

Deploy the backend using:

Start Command
node server.js
